# Flutter Portfolio

This portfolio showcases my skills, education, projects, and contact information.

## Features

 - About Me section

 - Education section

 - Skills section

 - Projects section

 - Email Me button

- GitHub profile link

- Responsive design

- Clean and modern UI

- Built with Flutter

## Architecture

The project follows a simple component-based structure:

``` screens/ — Main application screens.```

```widgets/portfolio/ — Reusable sections of the portfolio.```

```theme/ — Application colors, typography, and theme configuration.```

```assets/ — Images and other static resources.```

```main.dart — Application entry point.```

### Getting Started
1. Clone the repository
```git
2. git clone https://github.com/codewithabullah2005/my_flutter_portfolio.git
```

2. Navigate to the project
   cd my_flutter_portfolio
3. Install dependencies
   flutter pub get
```
4. Run the project
   flutter run
```

##  Build for Web

To build the portfolio for web:

flutter build web


The generated web application will be available inside:

build/web/
